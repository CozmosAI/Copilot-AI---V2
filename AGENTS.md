# Custom Skills & Rules for Copilot AI Gestão

The following skills are installed and must be actively used during development:

## Installed Skills

### 1. `grill-me` (`/skills/grill-me/SKILL.md`)
- **Purpose**: Calibrated stress-testing of plans, ideas, architecture, and decisions.
- **When to use**: When evaluating new features, reviewing architecture, or stress-testing implementation decisions before writing complex code.

### 2. `junior-to-senior` (`/skills/junior-to-senior/SKILL.md`)
- **Purpose**: Adversarial senior-engineer code and architecture review.
- **When to use**: Reviewing plans and implementations to eliminate "fog" (vague specifications) and "tunnel vision" (overly local hacks), ensuring production-ready quality.

### 3. `loop-factory` (`/skills/loop-factory/SKILL.md`)
- **Purpose**: Spec-driven iterative loop for managing tasks via structured specifications (`inbox/` -> `active/` -> `archive/`).
- **When to use**: When breaking down complex multi-step tasks into clear, testable, and verifiable criteria.

### 4. `interface-kit` (`/skills/interface-kit/SKILL.md`)
- **Purpose**: Implementation guidelines for stunning, accessible, and performant UI (typography, spatial grid, micro-interactions, dark/light themes, accessibility).
- **When to use**: Whenever building or refining frontend components, dashboards, modals, or user interfaces.

## General AI Agent Rules
- Always maintain high standards of code craftsmanship, accessibility (WCAG AA), and performance.
- Perform sanity checks and build verification before completing tasks.
- Keep the Mercado Livre / Meta Ads integrations full-stack and secure.
